# ☕ Kopi dan Nyemil

**Aplikasi Pemesanan Kopi dan Makanan Ringan Berbasis Android**

Kopi dan Nyemil merupakan aplikasi Android yang dirancang untuk memudahkan pengguna melihat pilihan menu kopi dan makanan ringan, memilih produk, serta melakukan simulasi pemesanan melalui perangkat Android.

Proyek ini dikembangkan sebagai bagian dari tugas mata kuliah **Pemrograman Mobile**.

---

## 📱 Tentang Aplikasi

Kopi dan Nyemil mengusung konsep kedai kopi modern dengan tampilan yang sederhana, elegan, dan nyaman digunakan. Aplikasi ini menggunakan kombinasi warna bernuansa kopi untuk memberikan pengalaman pengguna yang menarik.

## ✨ Fitur Utama

- **Splash Screen** – Tampilan pembuka aplikasi.
- **Welcome Page** – Halaman sambutan pengguna.
- **Sign Up** – Halaman pendaftaran akun.
- **Login** – Halaman masuk pengguna.
- **Register** – Halaman registrasi.
- **Home** – Menampilkan daftar menu makanan dan minuman.
- **Pencarian Produk** – Membantu pengguna menemukan menu.
- **Kategori Produk** – Pengelompokan menu berdasarkan kategori.
- **Profile** – Menampilkan halaman profil pengguna.
- **Delivery Address** – Halaman alamat pengiriman.
- **Keranjang dan Checkout** – Simulasi pemesanan produk.
- **Order Confirmation** – Halaman konfirmasi pesanan.

*Catatan: fitur di atas perlu disesuaikan dengan fitur yang benar-benar sudah berfungsi pada versi aplikasi yang diunggah.*

## 🚀 Cara Menjalankan Aplikasi

1. Clone repository ini:

```bash
git clone https://github.com/syamildh03-cmd/KopiDanNyemilsyam.git
```

2. Buka Android Studio.
3. Pilih **Open** dan arahkan ke folder proyek yang sudah di-clone.
4. Tunggu proses Gradle Sync selesai.
5. Hubungkan perangkat Android atau jalankan emulator.
6. Klik tombol **Run ▶** untuk menjalankan aplikasi.
